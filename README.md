# 📚 База учебников и AI Школьный Помощник · Узбекистан (1–11 класс)

**AI Maktab** — это универсальное веб-приложение (PWA) для школьников 1–11 классов в Узбекистане. Приложение работает со **своей базой учебников и словарей** на узбекском, русском и английском языках, поддерживает работу **полностью без интернета (офлайн)**, а при подключении бесплатного ключа **Google Gemini API** объясняет темы как живой школьный учитель.

---

## ✨ Основные возможности

* **Своя база учебников (1–11 класс):** добавляйте любые учебники, главы или конспекты текстом, файлами `.txt`, `.pdf` или готовой базой `.json`. Всё хранится в памяти вашего устройства (**IndexedDB** — десятки и сотни мегабайт без ограничений `localStorage`).
* **Школьный словарь (UZ / RU / EN):** отдельная база терминов, правил, дат и переводов. В комплекте идёт базовый пакет `dicts.json` для 1–11 классов, который загружается одной кнопкой.
* **Карточки по параграфам:** приложение автоматически разбивает учебники на удобные карточки (`§`, главы, параграфы) с мгновенным поиском, подсветкой слов и кнопкой **«Спросить»**.
* **Умный трёъязычный поиск:** понимает узбекский (латиницу и кириллицу: `oʻ / o' / ў`, `gʻ / ғ`, `q / қ`, `h / ҳ`), русский и английский языки, учитывает окончания слов.
* **Гибридный ИИ-чат (Офлайн + Gemini):**
  * **Без интернета / без ключа:** мгновенно находит точные цитаты, правила и формулы из ваших учебников и словаря.
  * **С ключом Gemini API:** находит нужные параграфы в вашей базе и передаёт их модели `gemini-2.5-flash`. ИИ объясняет тему простыми словами с учётом выбранного класса (от 1 до 11).
* **Безопасность и приватность:** никакой регистрации и сторонних серверов. Ваши книги и API-ключ хранятся **только в браузере вашего устройства**.
* **Установка на телефон (PWA) и Тёмная тема:** устанавливается на Android, iOS и ПК как обычное приложение, бережёт зрение благодаря переключению темы 🌙/☀️.

## 🚀 Как начать пользоваться

### Шаг 1. Загрузите базовый словарь
1. Перейдите во вкладку **«Словарь»**.
2. В блоке *«Базовый школьный словарь»* нажмите кнопку **«Загрузить с GitHub»** (или импортируйте файл `dicts.json`).

### Шаг 2. Добавьте свои учебники
1. Откройте вкладку **«Книги»**.
2. Выберите предмет (Математика, Алгебра, Физика, История Узбекистана, English и др.).
3. Вставьте текст параграфа или выберите сразу несколько файлов `.txt` / `.pdf`.
4. Нажмите **«Экспорт базы»**, чтобы сохранить резервную копию всех ваших книг и слов в один файл `baza-maktab.json`.

### Шаг 3. Задавайте вопросы в Чате
1. Откройте вкладку **«Чат»**.
2. Выберите **предмет** и **класс ученика (1–11)** — от этого зависит сложность объяснений.
3. Напишите вопрос на русском, узбекском или английском языке (или нажмите кнопку **«Спросить»** на любой карточке параграфа).

## 🤖 Как подключить ИИ-учителя Google Gemini (бесплатно)

По умолчанию приложение работает в офлайн-режиме (показывает выдержки из книг). Чтобы включить умные объяснения и пошаговый разбор задач:

1. Перейдите на официальный сайт **[Google AI Studio](https://aistudio.google.com/apikey)** и войдите в свой аккаунт Google.
2. Нажмите **Create API key** и скопируйте созданный ключ (начинается с `AIza...`).
3. В приложении откройте вкладку **«Чат»** и нажмите на строку:  
   **`⚙️ Настройки Gemini API (ключ хранится только в браузере)`**
4. Вставьте ключ в поле и нажмите **«Сохранить»**.
5. Выберите удобный режим:
   * *По учебникам + понятное объяснение учителя* — опирается на ваши книги и доступно разжёвывает тему для выбранного класса.
   * *Строго только по тексту учебников* — отвечает исключительно по загруженным материалам, ничего не добавляя от себя.

> 🔒 **Важно:** Ключ сохраняется только в `localStorage` вашего браузера и никогда не публикуется в GitHub.

## 📱 Установка на телефон (Android / iOS) и запуск

### Вариант 1. Через GitHub Pages (рекомендуется)
1. Загрузите все файлы репозитория на GitHub.
2. В настройках репозитория (**Settings → Pages**) выберите ветку `main` и папку `/ (root)`.
3. Откройте полученную ссылку `https://ВАШ_ЛОГИН.github.io/ИМЯ_РЕПО/` в браузере Chrome на телефоне.
4. Нажмите кнопку **«Установить»** в шапке сайта (или через меню браузера: **«Добавить на главный экран»**). После первого запуска приложение сможет работать офлайн.

### Вариант 2. Запуск из папки на компьютере или флешке
Вы можете скачать все файлы проекта в одну папку и открыть `index.html` двойным кликом в любом браузере.
* При локальном запуске (`file://`) для загрузки `dicts.json` используйте кнопку **«Импорт JSON»** во вкладке «Книги».

## 📁 Структура проекта

Проект состоит из 7 лёгких файлов без сборщиков и внешних зависимостей:

| Файл | Назначение |
| :--- | :--- |
| `index.html` | Разметка интерфейса (вкладки Книги, Словарь, Карточки, Чат) |
| `styles.css` | Адаптивный дизайн, мобильная вёрстка, светлая и тёмная темы |
| `app.js` | Логика базы данных IndexedDB, поиск UZ/RU/EN, чтение PDF, работа с Gemini API |
| `dicts.json` | Базовый школьный словарь терминов для 1–11 классов (UZ / RU / EN) |
| `sw.js` | Service Worker для кэширования файлов и работы без интернета (PWA) |
| `manifest.json` | Манифест веб-приложения для установки на главный экран смартфона |
| `icon.svg` | Векторная иконка приложения `AI · UZ (1–11)` |

## 💾 Резервное копирование и перенос на другое устройство

Чтобы перенести собранную коллекцию учебников и словарей на другой телефон или компьютер:
1. Во вкладке **«Книги»** нажмите **«Экспорт базы»** — скачается файл `baza-maktab.json`.
2. На другом устройстве нажмите **«Импорт JSON»** и выберите этот файл.
